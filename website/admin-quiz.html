Upload a .txt file in this format:
TITLE: Moderate : Quiz 1
GRADE: 11
TOPIC: Sequences
TIME_LIMIT: 20
DIFFICULTY: moderate
PAPER: paper1
CONTENT_TYPE: quiz
ACCESS_LEVEL: standard
SEND_EMAIL: false

NOTE: Consider the sequence...
QUESTION: What is 2+2?
A: 3
B: 4
C: 5
D: 6
E: 7 (optional)
F: 8 (optional)
ANSWER: B

Or for typed answers:
QUESTION: x^2 - 5x + 6 = 0
TYPE: text
INSTRUCTION: Enter each value separately.
ANSWER_FIELD: x|x =|
ANSWER_FIELD: y|y =|
ANSWER: x=2|y=3
ANSWER_MODE: number_tolerance
TOLERANCE: 0.01
POINTS: 2
SOLUTION:
Step 1: Factorise the quadratic
(x - 2)(x - 3) = 0

Step 2: Solve each factor
x = 2 or x = 3

Final Answer: x = 2 or x = 3

For a single answer with a unit:
INSTRUCTION: Give your answer to the nearest millimetre.
ANSWER_PREFIX: WX =
ANSWER_SUFFIX: mm
ANSWER: 24

Important numbering rule:
Use numbering in NOTE: lines like NOTE: 1.1 Consider the sequence...
Do not type numbering inside QUESTION: lines.
Example: QUESTION: Write down the next TWO terms...
